📸 Скриншотер страниц

Скриншоты сайтов и извлечение HTML любого элемента по CSS-селектору

    Пока пусто. Кликните по превью ниже, чтобы добавить клик, или добавьте шаг прокрутки/скриншота.

    Полноэкранная страница может сниматься дольше — подождите немного. Сценарий выполняется по шагам сверху вниз, в том порядке, в котором они добавлены: клик, прокрутка и «📸 Снимок здесь» — в любом сочетании и количестве. Шаг «📸 Снимок здесь» делает отдельный скриншот прямо в этой точке сценария — так за один запуск можно получить сразу несколько снимков на разных стадиях (например: снимок → клик → снимок → прокрутка → снимок). Если ни одного такого шага не добавить, снимок всё равно будет сделан — один, в самом конце, как раньше. Прокрутка идёт небольшими шагами с паузами (чтобы дождаться "ленивой" подгрузки контента), клик — "вслепую" по координатам, без ошибки, даже если там ничего интерактивного нет. Проще всего собирать сценарий постепенно: сделайте снимок → кликните по превью в галерее ниже, чтобы добавить шаг «Клик» в том месте, куда навели курсор → добавьте нужные шаги прокрутки/снимков → сделайте снимок ещё раз, чтобы увидеть результат и при желании добавить следующие шаги по новым превью.

    👆 Кликните по любой картинке выше, чтобы добавить шаг «Клик» в сценарий в этой точке (можно кликать несколько раз в разных местах и на разных снимках — они добавятся как отдельные шаги по порядку). Координата Y при снимке «Вся страница целиком» ограничивается высотой окна браузера, так как сам клик выполняется по видимой области окна.

    Возвращается полный HTML найденного элемента (outerHTML) — даже если он визуально скрыт на странице (например, служебная разметка для SEO или скринридеров).

    ⬇ Сохранить как .html

    Без селектора карточки рейсов находятся сами — по служебному описанию рейса, которое сайт вставляет в разметку для скринридеров (не зависит от CSS-классов). Указывайте селектор только если автопоиск не сработал или нужно ограничить область поиска. Из каждой карточки собирается: авиакомпания, номер рейса (или код авиакомпании, если номера нет в разметке — так часто бывает), вылет и прилёт (аэропорт, код, время), длительность, цена — и, если есть, информация о пересадке (город, длительность стыковки). Заточено под разметку в духе trip.com; на другой структуре страницы результат может быть неполным.
